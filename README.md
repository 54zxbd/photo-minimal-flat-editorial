# Photo Minimal Flat Editorial（照片极简扁平插画 · 改造版）

> 本仓库是基于 [ZzzLc0405/photo-abstract-editorial](https://github.com/ZzzLc0405/photo-abstract-editorial) 的**二次开发 / 深度改造版本**，原项目作者：ZzzLc0405（@AM.）。原项目仅限个人学习、研究、非商业用途，本仓库同样遵守该约定。

**把一张照片做成「原始摄影区域 ＋ 极简扁平矢量插画面板 ＋ 中英标题」的竖版编辑作品（1366×2048）。**

---

## 与原版的区别（本次改造点）

- **画风全面改路**：原版是"抽象色块记忆面板"，本版改为**极简扁平矢量插画**——用纯平涂色块、干净边界、适度几何化的形状重绘原图内容，**一眼认出主体、二眼才发现被极简了**。
- **背景忠实原图（而非留白）**：插画的背景必须**忠于原照片的空间占比与颜色**——天空 / 山峦 / 云海 / 雾 / 草坡占多少就画多少，天空要画成**连续铺展的色块平面**；象牙白 `#F3F0E8` **不是**默认底，只出现在原图本身空白 / 虚化处。
- **三种版式**（必须逐张判断，不能默认"上照片下插画"）：
  - **标准双联**——上原照片满宽 ＋ 下**忠于原图的完整插画** ＋ 底部中英标题；
  - **贯穿式联画**——画面有天然横向承接元素（地面/水面/屋面/栏杆/草地）时，分界线藏在横向元素里、元素跨线连贯，且为**有宽度的柔和过渡**；
  - **整张插画**——不做双联，整幅插画铺满上部（1366×1823）＋ 底部文字带，用于有寓意的复合场景。
- **新增"两步走"工作流**：先让模型**只画插画**（铺满画布、不要照片/双联/文字），再**本地合成**（原始照片像素 ＋ 插画 ＋ 中英标题 ＋ 角标 ＋ 署名行 → 精确 1366×2048）。这样照片区像素绝对不被模型碰，标题用真字体排，画幅精确，换任何模型都成立。
- **新增材质与细节规则**：毛发／毛皮主体必须用**同色系 2–4 个明度层次**做出体积并保留固有花纹（否则会被拍成一块纯色）；花蕊、昆虫翅脉等**细密结构要画出纹理、但要克制**（点／线须与基色同色系且更淡、稀疏成组，避免"黄底黑点"的芝麻饼观感）。
- **新增署名行**：素材来自图库（Pixabay / Unsplash / Pexels）时，自动在文字带底部加一行 `Photo by 作者 · 图库 — 来源链接`（仅作标注、不参与插画）。
- **新增命名规则**：`主体 + 行为/环境 + 两位随机数字`（纯中文，无英文前缀），例 `猫端坐92`、`双猫廊下26`。
- **新增避坑清单**：主体被裁切 / 被放大撑满、减少主体数量、猫画成纯色块或卡通老虎纹、毛发被拍成一块纯色、毯子像抹布、花心变成密集深色点、同心圆环光斑、手电筒锥形光束、石墙只画一条扁平色带、用留白替换实景天空……（详见 `SKILL.md`）。

## 使用方法

1. 将整个文件夹复制到你的 Skill 目录：Codex `~/.codex/skills/`、Claude Code `~/.claude/skills/`、豆包 `.user_skills/` 等。
2. 开启新对话，上传一张希望处理的照片。
3. 提出需求，例如："使用 photo-minimal-flat-editorial 把这张照片做成摄影＋极简扁平插画的竖向作品"。
4. 也可直接把 `references/` 下的提示词粘贴给任意图生图 / 图像编辑模型使用。

> ⚠️ `assets/examples` 中的图片来自原项目、仅用于理解"保留照片 ＋ 插画面板"的双联结构；本改造版的成图风格以 `references/` 的提示词为准。除非用户上传该图本身，否则不要复用其中的主题、色彩或构图。
