# Photo Minimal Flat Editorial Prompt（中文）

> 用途：把一张照片转成「原始摄影区域 ＋ 极简扁平矢量插画 ＋ 中英标题」的竖版作品（**1366×2048**）。
> 推荐**两步走**：先用【第一步】让模型只画插画；再用【第二步】本地合成。这样照片区像素绝对不被模型碰，标题用真字体排，画幅精确。

---

## 第一步 · 让模型只画"插画本身"

把下面整段作为**图生图 / 图像编辑**提示词，并附上原照片。`{在此填…}` 处按原图内容替换。

```
把这张照片画成一幅极简扁平矢量插画。

【只要插画本身】整幅画面就是一整张插画，铺满画布。不要出现照片、不要双联、不要上下分区、不要分界线、不要边框、不要任何文字。

【背景·忠于原图】插画的背景必须忠于原照片的空间占比与颜色，不是默认留白：
- 原图里天空／山峦／云海／雾／草坡各占多大面积，插画里就一一对应地占多大面积——照片是一整幅风景，插画就是一整幅风景，场景元素一个都不能删。
- 天空必须是连续完整的背景：天空、云海、霞光、雾气要作为大面积连续铺展的色块平面画出来，允许用几层色调相接的色带表达层次，但必须层层相接、把该区域铺满。绝不允许把一大片天空缩减成"浅色底上孤零零飘着几朵小云"。
- 颜色忠于原图：原片颜色丰富就画丰富，不归约成少量色块，绝不用留白去替换原图里本来就有的颜色与内容。
- 象牙白 #F3F0E8 留白不是默认背景：只有当原图该处本身就是空白／纯色／虚化时，才用干净色块概括。留白可以有，但不得占据画面主导、不得侵入或挤压主体与场景。
- 不要画框、不要画中画、不要矩形贴片——背景应当自然延续到画布四边。

【内容·忠于原照片】{在此填：主体的形态/姿态/朝向、颜色花纹特征、周围环境元素（天空/云海/山峦/雾/花枝/岩石/地面/植被等），以及"完整不被裁切"}

【画面完整·必须遵守】主体与关键元素必须完整位于画布之内、不被四边裁断（峰顶、主体头顶、关键枝叶绝不能切边）。但背景（天空、山峦、云海、雾、地面）要自然铺展到画布四边，不要为了留白而把背景缩成画面中央的一块。

【材质·毛发与织物·必须遵守】这是最容易翻车的地方：
- 毛发／毛皮主体（猫、狗、狼、羊、鸟等）绝不能画成一整块实心平色。必须用同一色系 2–4 个明度层次的色块做出毛发体积：受光面浅、中间调过渡、背光面与褶皱阴影深；用轮廓上与躯干内的几处圆钝分块／色阶交界暗示毛发的起伏与走向（不是锯齿状碎毛，也不是写实毛丝）。
- 主体自身的固有花纹必须画出来：虎斑条纹、斑点、深浅毛色交界、口鼻与胸腹的深浅对比、耳尖与四肢的深色——这些是"这是一只有毛的动物"的关键视觉信号，绝不能省成纯色。眼睛、鼻子、耳廓内、嘴部等五官必须清晰可辨。
- 织物（毛毯／绒毯／地毯／衣物）绝不能画成几块生硬的大色块拼贴（那会看起来像抹布）。要用同色系的明暗分层顺着褶皱走向分成若干柔和相接的块面——浅色受光、中灰凹陷、深色阴影，表现出柔软的起伏与绒毛感。

【细节·密纹理结构·必须遵守】原片里那些由大量细小单元构成的结构，必须用多层次的小色块／短笔触／细线画出纹理，绝不能用一整块纯色圆／纯色形状敷衍：
- 花蕊／花心／花盘（向日葵、雏菊、莲蓬等）：花盘不是一块纯色圆盘，要用密集的点簇或放射短线表现管状花／种子的颗粒感（2–3 个深浅层次）；雏菊类的黄色花心也要用细点或环状短线暗示细密质感，而不是一颗纯色圆点。
- 昆虫的翅膀与身体（蝴蝶、蜜蜂、蜻蜓等）：翅膀要画出翅脉／分区色块／边缘斑纹（如眼斑、翅缘深色带、翅室分割），不能是一块纯色形状；蜂类的身体要用条纹＋绒毛明暗分出胸腹与体节。
- 羽毛／叶脉／花药／鳞片同理：用分层的小色块或成组的短线表现走向与结构。
- ⚠️ 克制原则（重要）：纹理不是越密越好。密集的深色点阵会被看成"芝麻饼／蜂巢"，观感脏乱。点／线的颜色必须与所在基色同色系且更淡（如雏菊花心＝浅橙黄／暖黄点，绝不是深褐或黑点）；密度要稀疏、成组；首选「2 个同心色阶（亮色内盘＋略深暖色外环）＋外缘一圈稀疏短放射线」表达质感。远看该结构仍必须是一整块干净的基色。

【风格·关键】极简扁平矢量插画：用纯平涂色块概括，形状适度几何化、边界干净利落、分层清晰、有编辑质感；克制、概括，但不是减少元素——原图的层次、色彩与场景要画满。第一眼认出主体与场景，第二眼才发现被极简了。颜色全部取自原图（不发明原图没有的颜色）。注意：这里的"平涂色块"指不上渐变、边界干净，绝不等于"一整只动物只用一块颜色"——主体内部必须保留上述【材质】要求的明暗与花纹层次。
```

**负面词**（如模型支持 `negative_prompt`，一并传入）：

照片、真实照片、写实、双联、上下分区、分界线、边框、画框、画中画、矩形贴片式背景、任何文字、数字、色号、角标、logo、水印、主体被裁切、主体被放大撑满、主体被画成一团纯色块、卡通老虎纹、减少主体数量、同心圆环、手电筒锥形光束、亮黄圆形光斑、潦草线条、模糊、低分辨率、左右分栏、杂志排版、主体出画、象牙白空场取代实景背景与天空、把大片天空简化成几朵孤立小云、长毛动物被画成一整块无明暗无花纹的实心平色块、毛毯被画成几块生硬大色块拼贴、动物五官被简化到无法辨认、花心被画成一整块纯色圆、昆虫翅膀被画成一整块纯色形状、密集深色点阵（花心变成黄底黑点）

## 第二步 · 本地合成（照片 ＋ 插画 ＋ 标题 → 1366×2048）

版面比例（对齐参考成品实测）：

| 区域 | 位置 | 内容 |
|---|---|---|
| 照片区 | y 0–962（约 0–47%） | **原始照片像素**，满宽、完整不裁主体 |
| 插画面板 | y 962–1823（约 47–89%） | **忠于原图的完整插画**（原图的天空／云海／山峦／雾／草坡照原比例画满；不是"留白底上的小景"） |
| 文字带 | y 1823–2048（约 89–100%） | 英文衬线大标题（Title Case，约 88px，色 `#432619`）＋ 中文小字副标题（约 44px）＋（可选）素材署名行 |

- 左上角可加 `ORIGINAL PHOTO` 角标；右下角标 `#F3F0E8`。
- ⚠️ 原图若为 2:3 竖图、要塞进约 1.42:1 的横条，**必须下移偏置裁切**，居中裁会切掉主体。
- 素材若来自图库（Pixabay / Unsplash / Pexels），底部署名行写 `Photo by 作者 · 图库名 — 来源链接`，按许可要求留名。
- **整张插画版式**：照片区取消，插画直接铺满 y 0–1823，文字带不变。

## 三种版式怎么选

- **标准双联**：背景虚化散景 / 单个建筑正面 / 主体占高 >70% / 无明确小主体 → 下方是**忠于原图的完整插画**（不是象牙白底上的小景）。
- **贯穿式联画**：画面有**天然横向承接元素**（地面 / 水面 / 屋面 / 栏杆 / 草地）＋ 明确小主体 → 分界线藏在横向元素里、元素跨线连贯；分界线需**有宽度的柔和过渡**，不是硬直线。
- **整张插画**：画面是**有寓意的复合场景**（园林 / 古建 / 动物＋文物）→ 不做双联，插画铺满上部、只留底部文字带。

> 判版式三条硬门槛：①有没有能藏分界线的横向元素；②有没有体量适中的小主体；③主体会不会被切断难补。任一不过 → 走标准双联。

## 核心原则（按优先级）

1. **背景忠实（最高）**：原照片的天空／山峦／云海／雾／草坡占多少就画多少；天空等大面积背景必须画成**连续铺展的色块平面**；**绝不用留白替换原图本有的内容与颜色**，留白不得占主导、不得侵入画面。
2. **忠于原图**：不放大主体、不减少主体数量、不改姿态与朝向；颜色全部取自原图。
3. **极简 ≠ 删意义**：一眼认出主体，第二眼才发现被极简了；保留主体 **＋** 衬托客体（天空 / 光线 / 地面 / 代表性环境物）。
4. **材质要有层次**：毛发用同色系 2–4 个明度层次 + 固有花纹，织物用同色系柔和分层。
5. **密纹理要克制**：细密结构要画出纹理，但点／线须与基色同色系、更淡、稀疏成组，远看仍是干净的一整块。
6. **画面完整**：主体不被四边裁断，但**背景要自然铺展到画布四边**。
